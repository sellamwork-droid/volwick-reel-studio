# VOLWICK REEL STUDIO

Sistema condiviso per generare i reel Volwick da più computer e più sessioni di Claude.
Istruzioni complete: `CLAUDE.md`. Regole di Power: `REGOLE/PREFERENZE_E_FORMATI.md`. Installazione su un Mac: `00_SETUP/INSTALLA_REEL_STUDIO.command`, poi `VERIFICA.command`.
La coda dei video sono le Issues di questo repository (modello "Nuovo video").
Memoria condivisa: `MEMORIA/video/` (un file per video con stato, feedback di Power e lezioni). Inizio di ogni sessione: `git pull --rebase` e `python3 00_MOTORE/tools/studio.py brief`.
Guida per chi usa il sistema (3 pagine): `GUIDA_UTENTE.pdf`.
