# Brand identity

- **Name**: Volwick. Site: volwick.com. Launch: 28 October 2026.
- **Category**: market-structure terminal (dealer positioning, gamma maps, order flow) for active index traders.
- **Personality**: precise, calm, premium, technical without jargon walls. Never hype, never "get rich".
- **Voice rules**: short declarative sentences; numbers over adjectives; show the layer instead of claiming an edge; always "estimated" for dealer positioning; no dashes as punctuation; no emojis in ads.
- **Signature line** (closing only, never next to a data claim): SEE WHAT OTHERS CAN'T. Use sparingly; the research shows superiority lines read as hype in this category.
- **Legal entity**: TO BE CONFIRMED. Do not print a company name.
